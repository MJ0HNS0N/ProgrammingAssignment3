# ProgrammingAssignment3
- The bash script run_algo.sh calls the python script algo.py where the actual processing is
- The command line arguments of your program should be $ your_program <input_file_name> <EDF or RM> [EE]
- The parameters are the file name, the scheduling strategy (either EDF or RM), and optionally EE (which stands for energy efficient)
- Two example calls could be:
```$ ./run_alg.sh input.txt EDF EE```
```$ ./run_algo input.txt RM```
